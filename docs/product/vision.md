# Product Vision

Resume Generator turns a complete professional profile into a focused resume
for one vacancy while preserving factual integrity and a visible audit trail.

The product is a repository the user owns, not a hosted service. GitHub Issues
provide a familiar input and queue, the local machine protects the profile and
executes generation, and Pull Requests provide human review and artifact
history.

The project does not promise an ATS score, interview rate, or hiring outcome.
It promises a reproducible process that does not knowingly invent candidate
experience.
