# Architecture Decision Records

ADRs record decisions that constrain future implementation. They explain why
a choice exists; specifications describe the resulting behavior.

Statuses:

- `Proposed`: under discussion;
- `Accepted`: current decision;
- `Superseded`: replaced by a newer ADR.
